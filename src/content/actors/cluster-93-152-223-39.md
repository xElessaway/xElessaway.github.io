### Key Operational Findings

* **Targeted Lure Scheme**: The threat actor distributed malicious ISO archives mimicking Ukrainian PrivatBank payment invoices (`Payment invoice INV-15468869 13.08.2026 PrivatBank receipt.iso`).
* **Stealth Dropper**: Executes an MSHTA payload (`win.hta`) that decodes an in-memory XOR-encrypted Havoc Demon shellcode payload (`akt1842.dat`) using key `K7mQ2pL9`.
* **Persistence Mechanism**: Abuses Windows Task Scheduler via COM object `Schedule.Service` to overwrite `Microsoft\Windows\TextServicesFramework\MsCtfMonitor` with `Hidden = $true` triggered on `ONLOGON`.
* **Dual C2 Architecture**: Operates port `8089` (cleartext HTTP delivery) and port `9443` (TLS encrypted HTTPS C2 listener).
